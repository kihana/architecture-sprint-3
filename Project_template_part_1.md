# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи могут включать и выключать отопление. Также могут установить новую температуру

**Мониторинг температуры:**

- Пользователи могут узнать текущую температуру

### 2. Анализ архитектуры монолитного приложения

- Язык программирования: Java
- База данных: Postgres
- Архитектура: монолитная, все компоненты находятся в рамках одного приложения
- Взаимодействие: запросы обрабатываются синхронно

### 3. Определение доменов и границы контекстов

Выделил два домена:
- Управление устройствами - отвечает за управление системой отопления в помещении. Включение, выключение системы отопления и установку требуемой температуры.
- Мониторинг устройств - отвечает только за просмотр текущей температуры, взятой с температурного датчика, в помещении. 

### **4. Проблемы монолитного решения**

- сложность при обновлении - при любом изменении необходимо обновлять все приложение целиком
- все запросы обрабатываются синхронно - в целом негативно влияет на производительность и отзывчивость на стороне пользователя при большом количестве одновременных пользователей
- сложно масштабировать - при нагрузке на один определенный функционал придется масштабировать все приложение целиком
